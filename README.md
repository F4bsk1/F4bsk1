# Hi, I'm Fabian

I build AI products end to end: voice agents, matching engines, and the backends and
dashboards around them. Most of what I ship is Python and TypeScript.

## Things I've built

| Project | What it is | Stack |
|---|---|---|
| [Vakans](https://github.com/F4bsk1/vakans) | AI phone reception for Swedish clinics with a cancellation-refill engine and a live dashboard. A clinic's website becomes a personalised, runnable demo. | FastAPI, Postgres, Pydantic AI, ElevenLabs, Next.js |
| [Backchannel](https://github.com/F4bsk1/backchannel) | Agent-to-agent matchmaking for startups, built at the Accel Hackathon. Two-minute voice onboarding, then each person's agent privately screens the others. | Python, Anthropic, ElevenLabs, Supabase |
| [AI Visibility Checker](https://github.com/F4bsk1/ai-visibility-checker) | Scores whether a local business shows up when customers ask AI assistants for services in their city, and names the competitor that does. | Next.js 16, Brave Search, Claude, SQLite |
| [ReturnRun](https://github.com/F4bsk1/returnrun) | Landing page and waitlist for an on-demand return pickup service. | React, Vite, Tailwind, Supabase |
| [SchnitzelPredictor](https://github.com/F4bsk1/CS441-Final-Project) | Forecasts sales per menu item from point-of-sale history. | Python, SARIMA, XGBoost |

## How I like to work

- Demo-first: a cold URL should turn into something you can click within the hour.
- Fake providers for every external service, so the whole test suite runs offline.
- Deterministic guardrails after every model call. The model proposes, the code decides.
